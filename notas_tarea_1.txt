----- Enunciado Tarea 1 -----

Concepto: Sitio web de registro de aves en Chile con la Unión de Ornitólogos de Chile.
Detalle: Sistema que gestiona avistamientos de aves reportados voluntariamente.

Requerimientos:
1) Formulario solicitando datos de la persona (nombre y apellido, correo electrónico, código postal, región y comuna).
2) Registro de avistamientos para usuarios registrados en el sitio web, que incluye: tipo, nombre, lugar, fecha, hora y imagen/video del encuentro.
3) Listado de avistamientos con filtros por tipo de ave, fecha, lugar. Tiene formato de múltiples páginas.
4) Indicadores/métricas sobre usuarios y avistamientos registrados.
*) Uso de HTML (HTML5), CSS (CSS3) y JS.
*) Cada campo aclara si es obligatorio u opcional.
*) No hay uso excesivo de <div>.
*) Se definen reglas de validación de datos.
*) La entrega es por GitHub en repositorio "desarrollo_web_diego_salinas" (branch "Tarea 1"). Debe contener un README.
*) La entrega también es por zip adjunto en U-Cursos.

----- Elementos básicos sitio web -----

- Header: cabecera con marca, navegación y controles globales del usuario.
- Hero: título principal, imagen/video y llamado a la acción.
- Main: contenedor de todo el contenido central.
- Article: bloque temático independiente en el Main.
- Aside: barra lateral complementaria.
- Footer: cierre de página con enlaces y contacto.
